01 / COMPLETE STRUCTURE

Company → Branch → Franchise

A staff-operated logistics platform. Example company: Chandhu Logistics.

COMPANY REGISTRATION
  └─ Company login
      ├─ Purchase booking subscription
      │   └─ Example: INR 5,000 → 10,000 company bookings
      │
      └─ CHANDHU LOGISTICS COMPANY PORTAL
          ├─ Company setup
          │   └─ Domestic / International / Both
          ├─ Company super admin & team
          ├─ Own branches
          │   └─ Branch admin / operational staff
          ├─ Franchise branches
          │   ├─ Created by company / company super admin
          │   ├─ Access given to franchise staff
          │   └─ Company records amount & booking allowance
          ├─ External services
          │   └─ Purchase / enable → Connect → Branch access
          ├─ Staff bookings
          │   ├─ Own coverage → Own logistics
          │   └─ No own coverage → Connected courier service
          ├─ Shipment operations & tracking
          ├─ Company / franchise booking-count ledger
          └─ Reports under Chandhu Logistics
Branding & responsibility

Franchises operate under the parent logistics company’s name. Branches, bookings, staff and reports belong to that company. The customer provides shipment information; company/branch staff uses the portal.

Where Ciyash appears

Ciyash is the platform provider for company subscription / booking packs and external-service enablement fees. It does not appear as an operational branch or as the company super admin. The super admin discussed here belongs to Chandhu Logistics.

Document scope

This is the latest proposed flow incorporating company subscriptions and franchises. It supersedes the earlier unlimited-booking demo assumptions for planning purposes. The current dummy site does not yet implement this full franchise/quota model.

RuleExpected behaviour
Inherited servicesA franchise only gets the categories and enabled services offered by its parent company.
No third-party entitlementIf the company has no enabled external service, its franchises cannot use that external service. Show the company admin an enablement action; do not silently allow booking.

03 / BOOKING DECISION

Address first. Own network first.

Domestic / International describes the route. Own / External describes who handles the shipment.

STAFF LOGIN → NEW BOOKING
  ├─ Customer supplies address & parcel information
  ├─ Select Domestic / International (company-enabled only)
  ├─ Enter sender, receiver, pickup & destination addresses
  ├─ Enter contents, packages, weight, dimensions & value
  │
  ├─ CHECK COMPANY NETWORK COVERAGE
  │   ├─ Route served by the company’s branch network
  │   │   └─ Own logistics → Branch route → Freight charges
  │   └─ Route not served
  │       ├─ Show enabled / connected external services
  │       ├─ Show available services & shipping charges
  │       ├─ Staff selects service
  │       └─ Selected courier form → Required details
  │           └─ Validate service / quote before confirmation
  │
  ├─ International shipment
  │   └─ Declaration + invoice + required documents
  │       + goods value / currency + duties responsibility
  │
  └─ REVIEW → CHECK QUOTAS → CONFIRM BOOKING
      ├─ Success → Save CRM record → Consume booking count
      │   ├─ Own: Shipment ID / GRN / LR / Receipt
      │   └─ External: Shipment ID / AWB / Provider documents
      ├─ Failure → Do not consume count / release reservation
      └─ Pending → Reconcile status; avoid duplicate booking
Four supported combinations

Domestic + own logistics; Domestic + external courier; International + own overseas network; International + external courier. Own coverage must be based on the actual company service area, not only a similar branch name or city.

User-friendly service screen

Keep the CRM consistent. Use common sender/receiver/parcel fields, show connected provider options clearly, then show the selected provider’s additional fields. Whether exact rates can appear before its form depends on the data required by that provider; rate-check timing is an implementation detail to confirm.

Records remain in the company CRM

Store the company, branch/franchise, category, fulfilment, selected service, provider reference, charges, identifiers and shipment events. This allows company-wide and franchise-wise reports.

04 / BOOKING QUOTAS

One company quota. Branch allowances.

Franchise allocations do not consume the purchased company quota. Actual bookings do.

CHANDHU LOGISTICS: PURCHASED COMPANY QUOTA = 10,000
  ├─ Own branches use the company quota
  ├─ Franchise A: allowance assigned by Chandhu Logistics
  └─ Franchise B: allowance assigned by Chandhu Logistics

FOR EACH BOOKING
  ├─ Company remaining quota must be available
  ├─ Franchise remaining allowance must also be available
  │   └─ For a franchise booking
  └─ Confirmed successful booking
      ├─ Company remaining: -1
      └─ Applicable franchise remaining: -1

FAILURE / ELIGIBLE CANCELLATION
  ├─ Failed: do not consume, or release reserved count
  ├─ Successfully cancelled before loading
  │   ├─ Company remaining: +1
  │   └─ Applicable franchise remaining: +1
  └─ Loaded shipment: cancellation not allowed
Example eventCompany remainingFranchise A remaining
Starting balance10,0001,000
Franchise A booking succeeds9,999999
That booking is cancelled before loading10,0001,000
Proposed exhaustion solution

Franchise allowance exhausted → only that franchise’s new bookings stop; company admin can top up its allowance. Company quota exhausted → all branches’ new bookings stop until additional quota is purchased. Existing booked shipments continue through tracking, operations and delivery.

Allocation can exceed company quota

The company may assign franchise allowances as it chooses, even if their total is larger than the company quota. All branches together still cannot consume more actual bookings than the purchased company balance.

Count accuracy

Use one auditable booking-count record per consume/restore action. Concurrent bookings must not exceed available quota. Retries or repeated cancellation requests must not restore a count twice.
